# Bhaskar Aryal | Portfolio

Next.js (App Router) portfolio: Home, About, Skills, Projects (a case-study page per project) and Contact.

## Run
    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

## Edit your content
Almost everything lives in `lib/data.js`: name, email, links, bio, skills, education and projects.
Your photo is `public/profile.jpg`. Project media is in `public/projects/`.
